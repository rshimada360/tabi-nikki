# 旅の手帖

都道府県ごとに、旅先の写真や動画を vlog のように綴じていくセピア色の旅日記アプリです。
iPhone の Safari で開き、「ホーム画面に追加」するとアプリとして使えます（PWA）。

- 最初の画面は日本地図。都道府県をタップするとその土地のアルバムが開きます（二本指で拡大、下の目次からも開けます）
- アルバムでは「写真・動画を貼る」から写真・動画をまとめて追加できます
- 撮影日（写真の EXIF）ごとに「DAY 01, DAY 02…」と章に分かれ、大小さまざまなコラージュで並びます
- 動画は画面に入ると音なしでループ再生されます
- タップすると全画面で表示。メモや日付の編集、共有・保存（「画像を保存」で写真アプリへ）、削除ができます

写真と動画は **その iPhone のブラウザの中（IndexedDB）にだけ** 保存されます。どこにも送信されません。

## iPhone で使う方法

### A. まず試す（PC と iPhone が同じ Wi-Fi）

1. このフォルダで `python serve.py` を実行
2. 表示された `http://192.168.x.x:8000/` を iPhone の Safari で開く
3. 共有ボタン →「ホーム画面に追加」

この方法は PC でサーバーが動いているときしか開けません。また、PC の IP アドレスが変わると
別のアプリ扱いになり、それまでの記録が見えなくなります。お試し用です。

### B. ずっと使う（HTTPS で公開して、ホーム画面に追加）

このフォルダの中身をそのまま静的サイトとして HTTPS で置きます（GitHub Pages、Netlify、Cloudflare Pages など。無料で使えます）。
置くのはアプリのプログラムだけで、写真は各 iPhone の中に保存されるので公開されません。

1. 公開した URL を iPhone の Safari で開く
2. 共有ボタン →「ホーム画面に追加」
3. 以後はホーム画面のアイコンから起動。一度開けば、電波がなくても起動できます

## 注意

- 記録はこの iPhone の中にしかありません。アプリ（ホーム画面のアイコン）を削除したり、
  Safari の「履歴と Web サイトデータを消去」をすると記録も消えます。大切な写真は元の写真アプリにも残しておいてください
- ホーム画面に追加して使うのがおすすめです（Safari のタブで開くだけだと、長期間使わないとデータが消されることがあります）
- 地図データ: 国土数値情報をもとにした [dataofjapan/land](https://github.com/dataofjapan/land) を簡略化して使用

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | セピア調のデザイン |
| `app.js` | 地図、アルバム、保存、ビューアの処理 |
| `japan-map.js` | 都道府県の地図データ（自動生成） |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面アプリ化・オフライン用 |
| `serve.py` | 同じ Wi-Fi で試すための簡易サーバー |
